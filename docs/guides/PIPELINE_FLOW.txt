STAGE 1: INGESTION
===============================================================================

Function: ingest(file_path) → normalized_text
File: core/ingestion.py

Input:  contract.pdf
        ↓
  ├─ pdfplumber.open(file_path)
  ├─ Extract text from each page
  ├─ Normalize (4-step process):
  │   ├─ Strip repeating headers/footers
  │   ├─ Drop standalone page numbers
  │   ├─ Rejoin hyphenated line breaks
  │   └─ Collapse whitespace, preserve paragraph breaks
  ├─ Return canonical document (byte-identical on re-run)
  │
Output: normalized_text (string)
        ├─ Byte position 0: "1. Term and..."
        ├─ Byte position 10500: "2. Limitation..."
        └─ Byte position 20048: (end)

Guarantee: Same file → byte-identical output (offsets are precious)

===============================================================================
STAGE 2: EXTRACTION
===============================================================================

Function: extract(text, contract_id) → List[Clause]
File: core/extraction.py

Input: normalized_text
       ↓
  ├─ Apply regex: ^\s*(\d+(?:\.\d+)*)\s*\.?\s+
  ├─ For each match:
  │   ├─ Extract number: "5.2"
  │   ├─ Extract heading: "Limitation of Liability"
  │   ├─ Find text run until next match
  │   ├─ Record char_start (offset into normalized_text)
  │   ├─ Record char_end (offset into normalized_text)
  │   ├─ Detect cross-references: "Section 8.2" → clause_id
  │   └─ Create Clause object
  ├─ Resolve xrefs: check which clause IDs actually exist
  │
Output: List[Clause]
        ├─ Clause(id="acme::5.2", number="5.2", char_start=10500, char_end=10700)
        ├─ Clause(id="acme::9.1", number="9.1", char_start=12000, char_end=12200)
        └─ ... (47 clauses total)

Key: char_start/char_end are byte offsets, validated by smoke test

===============================================================================
STAGE 3: CLASSIFICATION
===============================================================================

Function: classify(clauses) → List[Clause]
File: core/classification.py

Input: List[Clause] (47 clauses, no labels yet)
       ↓
  ├─ For each clause:
  │   ├─ Lowercase clause text
  │   ├─ For each label type in KEYWORDS:
  │   │   ├─ Check if any keyword appears in text
  │   │   ├─ If match: append label with confidence=1.0
  │   │   └─ Move to next label
  │   └─ Next clause
  ├─ KEYWORDS dict:
  │   ├─ "indemnification": ["indemnif", "hold harmless", ...]
  │   ├─ "limitation_of_liability": ["limitation", "in no event", ...]
  │   ├─ "termination": ["terminate", "termination for cause", ...]
  │   └─ ... (11 label types total)
  │
Output: List[Clause] (same 47 clauses, now with labels)
        ├─ Clause(id="acme::5.2", labels=[{"label": "limitation_of_liability", "confidence": 1.0}])
        ├─ Clause(id="acme::9.1", labels=[{"label": "indemnification", "confidence": 1.0}])
        └─ ... (31 labeled clauses, 16 unlabeled)

Quality: Keyword matches are correct but incomplete (LegalBERT comes week 5)

===============================================================================
STAGE 4: CANDIDATE SELECTION
===============================================================================

Function: select_candidates(clauses, config) → List[tuple]
File: core/candidate_selection.py

Input: List[Clause] (47 clauses, classified)
       config: {"top_k": 5}
       ↓
  ├─ Method A: BM25 SCORING
  │   ├─ Tokenize each clause text
  │   ├─ For each clause_a:
  │   │   ├─ Score all other clauses via TF-IDF
  │   │   ├─ Keep top-5 by score
  │   │   └─ Add pairs to candidates with surfaced_by=["bm25"]
  │   └─ Result: ~40 pairs
  │
  ├─ Method B: CROSS-REFERENCE PAIRING
  │   ├─ For each clause_a:
  │   │   ├─ For each xref in clause_a.xrefs:
  │   │   │   ├─ If xref.resolved == True:
  │   │   │   │   └─ Add (a, b) pair with surfaced_by=["xref"]
  │   │   └─ Next xref
  │   └─ Result: ~15 pairs
  │
  ├─ Method C: TYPE MATRIX (Label Pair Conflicts)
  │   ├─ TYPE_MATRIX = {
  │   │   ("limitation_of_liability", "indemnification"): True,
  │   │   ("termination", "survival"): True,
  │   │   ("assignment", "confidentiality"): True,
  │   │   ...
  │   │ }
  │   ├─ For each (label_a, label_b) marked as conflict:
  │   │   ├─ Find all clauses with label_a
  │   │   ├─ Find all clauses with label_b
  │   │   ├─ Pair each clause_a with each clause_b
  │   │   └─ Add to candidates with surfaced_by=["type_matrix"]
  │   └─ Result: ~20 pairs
  │
  ├─ DEDUPLICATION
  │   ├─ Merge pairs with same (a_id, b_id)
  │   ├─ Combine surfaced_by lists: ["bm25", "type_matrix"]
  │   └─ Cap at ~30 pairs
  │
Output: List[tuple]
        ├─ ("acme::5.2", "acme::9.1", ["type_matrix", "bm25"])
        ├─ ("acme::1.0", "acme::3.1", ["xref"])
        ├─ ("acme::2.0", "acme::4.2", ["bm25"])
        └─ ... (28 pairs)

Insight: Same pair found by 2+ methods = higher confidence it's real
