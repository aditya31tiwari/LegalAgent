CORE PIPELINE (The Implementation)
================================================================================

DIRECTORY: core/

FILE: core/__init__.py
TYPE: Python package init
PURPOSE: Export public API (Clause, Finding, Run, analyse)
SIZE: ~200 bytes
STATUS: ✓ Complete
KEY EXPORTS: Clause, Finding, Run, analyse

FILE: core/types.py
TYPE: Data structures
PURPOSE: Define final Clause, Finding, Run dataclasses
SIZE: ~1 KB
STATUS: ✓ Complete (FINAL - don't change without consensus)
KEY CLASSES: Clause, Finding, Run
GUARANTEE: Field names match DB columns exactly

FILE: core/ingestion.py
TYPE: Stage 1 implementation
PURPOSE: Load PDF/DOCX/TXT, normalize to canonical text
SIZE: ~1.5 KB
STATUS: ✓ Complete
KEY FUNCTIONS: ingest(file_path) → str, normalize(text) → str
GUARANTEE: Byte-identical on re-run

FILE: core/extraction.py
TYPE: Stage 2 implementation
PURPOSE: Regex-based clause extraction (decimal numbering)
SIZE: ~1.5 KB
STATUS: ✓ Complete (v0 only: decimal numbers, no hierarchies)
KEY FUNCTIONS: extract(text, contract_id) → List[Clause]
KEY REGEX: ^\s*(\d+(?:\.\d+)*)\s*\.?\s+
FEATURES: char_start/char_end offsets, xref detection/resolution

FILE: core/classification.py
TYPE: Stage 3 implementation
PURPOSE: Keyword-based clause labeling
SIZE: ~1 KB
STATUS: ✓ Complete (v0: keyword dictionary, confidence=1.0)
KEY FUNCTIONS: classify(clauses) → List[Clause]
KEYWORDS: 11 label types (indemnification, liability, termination, ...)

FILE: core/candidate_selection.py
TYPE: Stage 4 implementation
PURPOSE: BM25 + xref + type_matrix pair generation
SIZE: ~2 KB
STATUS: ✓ Complete
KEY FUNCTIONS: select_candidates(clauses, config) → List[tuple]
METHODS: BM25 scoring, cross-reference pairing, type matrix
TYPE_MATRIX: Label pairs that commonly conflict

FILE: core/pipeline.py
TYPE: Orchestration + Stage 5 (stub)
PURPOSE: Chain all stages together, stub LLM analysis
SIZE: ~1.5 KB
STATUS: ✓ Complete (v0: analysis stubbed)
KEY FUNCTIONS: analyse(file_path, config) → (Run, List[Clause], List[Finding])
STUB: analyse_pair_stub() returns None (upgrade on Day 9)
